## 1. Clone the Repository

Open a terminal and run:

```bash
git clone <repository-url>
cd CSCI467-GroupProject
```

Replace `<repository-url>` with the GitHub repository URL.

## 2. Backend Setup

Navigate to the backend directory:

```bash
cd backend
```

Install dependencies:

```bash
npm install
```

### Environment Variables

Create a file named `.env` inside the `backend` directory.

Following the guide in env.example


### Start the Backend

Once the Express server files have been implemented, run:

```bash
npm run dev
```

## 3. Frontend Setup

Open another terminal and navigate to the frontend directory from the project root:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start React:

```bash
npm run dev
```

## 4. Running the Project

Once the backend is configured, run the frontend and backend in separate terminals.

**Terminal 1 — Backend**

```bash
cd backend
npm run dev
```

**Terminal 2 — Frontend**

```bash
cd frontend
npm run dev
```

Press `Ctrl + C` in either terminal to stop its server.

## Brief Project Description

The AutoParts Store is a web-based system that allows customers to browse and purchase automotive parts online.

The system will also include several internal dashboards used by employees and administrators to manage inventory, receive products, process orders, handle shipping, and perform other store operations.

* Support credit card payment processing
* Develop a database system for storing and managing project data

* Create a receiving dashboard for incoming inventory
* Create an administrative dashboard
* Support inventory management
* Support shipping and order fulfillment
